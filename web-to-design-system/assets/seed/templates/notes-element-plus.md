- **样式来源**：样式入口按顺序引入 Element Plus → `design-system/dist/index.css` → 桥接 `{{BRIDGE}}/{element-plus.css, iconpark.css}` → 配方层 `{{BRIDGE}}/recipes.css` → 项目补充 `app.css`。桥接与配方是上游只读快照 / npm 包，不改；页面 `<style scoped>` 与 `app.css` 只引用 token 变量（`--color-*`、`--spacing-*`、`--space-*`、`--text-*`、`--control-*`、`--radius-*`、`--border-*`、`--elevation-*`），不写色值与像素字面量。像素只允许出现在按内容定的宽度（表格列宽、筛选控件宽度）上。
- **桥接是从 Citrine 拷来的起点**：它把 Element 的 `--el-*` 变量与 20+ 处写死的主色 / 焦点 / 色表逐条接到语义 token 上，这部分对任何系统都成立；但里面也带着 Citrine 的品牌决定（hover 不出现品牌色、选中用深黑反转块、状态色只做浅底胶囊）。第一次接入前照 `design-system/AUDIT.md`「桥接缺口」补齐缺的 token 或删掉对应规则，再挂走查页 `{{IMPORT}}/vue/KitchenSink.vue` 到 `/kitchen`，亮 / 暗两种模式下逐组件看一遍 hover / focus / disabled。
- **页面骨架用配方类，不自己重写**（`recipes.css`）：壳层 `.app/.sidebar/.topbar`、页头 `.page-head`、筛选栏 `.filter`、状态胶囊 `.status.*`、操作胶囊 `.act`、表单页 `.form-page`、空态 `.empty`、统计卡 `.stats`；配方组件在 `{{IMPORT}}/vue/*`（StatCard / EChart / TrendChart / TableSkeleton / ConfirmBar），图表主题来自 `{{IMPORT}}/echarts`（运行时读 token）。
- **另一模式**：按 `design-system/theme-map.json` 的激活方式切换（class 激活 = `<html class="dark">`）；不要引 Element 的 dark css-vars。
- **验收**：改完 UI 运行 steward `guard.mjs --project $PWD`（应为 `current`）与 `status.mjs`；对比度基线用 `check-contrast.mjs --system design-system`。
