- **样式来源**：样式入口按顺序引入 `design-system/dist/index.css`（token：默认模式 + 其他模式 delta）→ 基础桥接 `{{BRIDGE}}/base.css`（body / 标题 / 链接 / 表单控件 / 焦点 / 减少动态效果）→ 项目补充 `app.css`。桥接是上游只读快照 / npm 包，不改；页面样式与 `app.css` 只引用 token 变量（`--color-*`、`--spacing-*`、`--space-*`、`--text-*`、`--control-*`、`--radius-*`、`--border-*`、`--elevation-*`、`--motion-*`、`--layer-*`），不写色值与像素字面量。像素只允许出现在按内容定的宽度（表格列宽、筛选控件宽度）上。
- **组件怎么写**：按 `design-system/DESIGN.md`「组件配方」表逐个角色取变量——主按钮 `--color-action-primary` + `--color-text-on-primary`，高度 `--control-height-md`，圆角按容器层级取 `--radius-*`；卡片 `--color-bg-surface` + `--color-border-default` + `box-shadow: 0 var(--elevation-card-y) var(--elevation-card-blur) var(--elevation-card-color)`；状态胶囊 `--color-status-<x>` 配 `--color-status-<x>-bg`。配方表里写「待确认」的行接入前先确认。
- **另一模式（如暗色）**：按 `design-system/theme-map.json` 的激活方式切换（class 激活 = `<html class="dark">`，data 属性激活 = `<html data-theme="dark">`，媒体激活 = 跟随系统偏好、无需切换代码）。首屏前读 localStorage / `?theme=` 避免闪烁；运行时所有者在 `themes/<id>/THEME.md` 里登记。
- **组件库**：本种子只带纯 CSS 桥接。项目用了 Element Plus / shadcn / Ant Design 等组件库时，组件默认外观不会自动跟随 token——需要一份逐组件接管的桥接，那是系统层工作，向设计系统维护者提提案，不在页面上就地补样式。
- **验收**：改完 UI 运行 steward `guard.mjs --project $PWD`（应为 `current`）与 `status.mjs`（页面字面量清零）；对比度基线按 `DESIGN.md`「验收基线」，工具 `check-contrast.mjs --system design-system`。
